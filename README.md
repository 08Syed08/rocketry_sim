# 🚀 Rocket Fin Structural Analysis using SimScale

A Computational Engineering project focused on the structural analysis of a rocket fin using **SimScale**. The project evaluates the structural response of the fin under an applied aerodynamic pressure using **Finite Element Analysis (FEA)**.

---

## 📌 Project Overview

Rocket fins play an important role in maintaining the stability and trajectory of a rocket during flight. Since fins are exposed to aerodynamic forces, they must be capable of withstanding the resulting loads while maintaining acceptable structural deformation.

In this project, a rocket fin was analyzed using **SimScale Static Structural Analysis**. An external pressure load was applied to the fin to represent an aerodynamic loading condition, and the resulting **von Mises stress** and **maximum displacement** were evaluated.

The project demonstrates a basic CAE workflow for analyzing the structural behavior of a rocket fin and provides a foundation for further CFD analysis, material comparison, and structural optimization.

---

## 🎯 Objectives

- Model a rocket fin for structural analysis.
- Perform Finite Element Analysis using SimScale.
- Apply an aerodynamic pressure load to the fin.
- Assign aluminium as the structural material.
- Generate an appropriate computational mesh.
- Perform static structural analysis.
- Determine the von Mises stress distribution.
- Determine the maximum displacement of the fin.
- Interpret the structural response under the applied loading condition.
- Establish a foundation for future CFD and optimization studies.
